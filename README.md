# 뽀모도로 타이머

분과 초를 고르면 남은 시간이 원판으로 줄어드는 ADHD 친화 뽀모도로 타이머예요.
디자인은 수업 활동지의 "파스텔 레트로 OS"([`design/README.md`](design/README.md))를 따르고, 색·글꼴은 [`design/tokens.css`](design/tokens.css)의 `msi-` 토큰만 써요.

## 쓰는 법

1. 큰 시계의 바늘 끝 화살표를 끌어서 분을 맞춰요(5분씩). 옆 작은 시계로 0초/30초를 골라요.
   드롭다운으로는 1분·1초 단위로 맞출 수 있고, 바늘과 드롭다운은 서로 따라 움직여요.
2. 지금 할 일을 적으면(안 적어도 돼요) 타이머 화면 위에 계속 보여요.
3. **시작하기**(또는 Enter). 숫자와 원판이 함께 줄어들고, 마지막 1분은 노란색과 "곧 끝나요"로 알려 줘요.
4. 끝나면 알림음이 3번 울리고 "시간 다 됐어요!" 카드가 떠요. 쉬는 시간(1~30분)을 골라 쉬거나, 다시 집중하거나, 처음으로 돌아가요.

- 제목줄: **알림음** 켜기/끄기 · **전체 화면**(TV·전자칠판).
- 타이머 화면: 스페이스 = 멈추기/계속하기. **그만하기**는 한 번 더 물어봐요(Esc = 계속하기).
- 새로고침해도 진행 중인 타이머가 이어져요. 설정과 오늘 집중한 횟수는 이 기기에만 저장돼요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 3개 — 첫 화면 · 타이머 · 끝난 화면 |
| `app.css` | 모양. 타이머에만 있는 색은 `--msi-role-timer-*` 역할 토큰으로 더함 |
| `app.js` | 동작 — 시계 끌기·화살표 키, 타이머, 알림음 예약, 화면 꺼짐 막기, 저장 |
| `design/` | 디자인 토큰·부품·글꼴(수업 활동지와 같은 것) |
| `favicon.svg` | 탭 아이콘 |
